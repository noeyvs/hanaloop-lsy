# Project Architecture

## 🏗️ Stack
- **Framework**: Next.js 15 (App Router)
- **Language**: TypeScript
- **Styling**: Vanilla CSS (Next.js CSS Modules)
- **Visualization**: Recharts
- **Icons**: Lucide React
- **Database**: PostgreSQL (Planned with Prisma)

## 📁 Folder Structure
- `client/src/app`: Page routes and layouts
- `client/src/components`: Reusable UI components
- `client/src/lib`: Utility functions and data fetching
- `client/src/styles`: Global styles and CSS variables

## 🚀 Key Features
1. **PCF Dashboard**: Visualizing product carbon footprint data from activity data.
2. **Data Import**: Interface to import data from Excel (readme.xlsx).
3. **Emission Factor Management**: Versioned tracking of emission factors.
