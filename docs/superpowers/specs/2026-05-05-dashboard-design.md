## 1. 개요

탄소 배출량을 측정·관리·감축하는 하나루프(Hanaloop) 플랫폼의 **PCF 전과정 데이터를 시각화하는 인터랙티브 분석 대시보드**입니다.

**목표**: 실무자 및 분석가가 제품별 탄소 발자국(PCF)을 직관적으로 분석하고, 감축 전략을 수립할 수 있는 환경 제공

## 5. 핵심 기능 상세 설계

### 5.1 분석 대시보드

#### 5.1.1 필터 시스템 (상단 필터바)
모든 필터는 **조합 가능**(AND 조건)하며, URL 쿼리 파라미터로 상태 유지:

| 필터 | 옵션 | 효과 |
|------|------|------|
| **제품** | 드롭다운 (다중선택) | 특정 제품만 분석 |
| **기간** | 날짜 범위 선택 | 월/분기/연도 데이터 |
| **Scope** | Scope 1, 2, 3 (다중선택) | 배출 범위 필터링 |
| **공급망 단계** | 원재료, 생산, 물류, 판매 등 (다중선택) | 단계별 배출 원인 분석 |

**리셋 버튼**: 모든 필터 초기화

#### 5.1.2 핵심 지표 (KPI 카드)
필터 적용 후 계산된 **병렬 표시** (3개 카드):

1. **총 배출량** (tCO₂e)
   - 선택된 필터 범위 내 전체 배출량
   - 색상: 빨강 (높을수록 진함)

2. **월별 감축율** (%)
   - 지난달 대비 감축 비율
   - 색상: 초록 (감축) / 빨강 (증가)

3. **배출 범위 분류** (Scope 1, 2, 3)
   - 각 범위별 비율
   - 클릭 시 해당 Scope 필터 자동 적용

#### 5.1.3 차트 영역 (2×2 그리드)

**좌상단: 제품별 PCF (막대 차트)**
- X축: 제품명
- Y축: 배출량 (tCO₂e)
- 상호작용: 마우스 호버 시 상세값 표시, 클릭 시 드릴다운

**우상단: 시간 추이 (선 차트)**
- X축: 날짜 (선택된 기간)
- Y축: 배출량 (tCO₂e)
- 범례: 필터 적용된 조건

**좌하단: Scope 비율 (도넛 차트)**
- 중앙: 총 배출량
- 각 섹션: Scope 1, 2, 3
- 클릭 시 해당 Scope 필터 활성화

**우하단: 공급망 단계별 기여도 (트리맵)**
- 각 영역 크기 = 배출량
- 색상 = Scope 분류
- 클릭 시 해당 단계로 필터링

### 5.2 데이터 임포트

#### 5.2.1 임포트 흐름 (간단한 4단계)
1. **파일 선택**: "파일 선택" 버튼 → Excel 업로드
2. **검증**: 파일 형식, 필수 열 검사
3. **미리보기**: 임포트될 데이터 표시 (처음 5행)
4. **저장**: "저장" 버튼 → DB 저장 완료

#### 5.2.2 지원 형식
- **파일**: .xlsx, .xls
- **필수 열**: 제품명, 원재료(kg), 전기(kWh), 운송(km), 배출계수 코드
- **검증**: 숫자 형식, 필수값 확인, 배출계수 코드 존재 여부

#### 5.2.3 에러 처리
- **파일 형식 오류**: "지원하지 않는 형식입니다. (xlsx, xls만 가능)"
- **필수 열 누락**: "필수 열이 누락되었습니다: [열명]"
- **데이터 형식 오류**: "행 5의 '전기' 값이 숫자가 아닙니다"
- **배출계수 미등록**: "행 3의 배출계수 코드 'EF-001'을 찾을 수 없습니다"

### 5.3 배출계수 관리

#### 5.3.1 배출계수 테이블
- 배출계수 코드 (EF-001, EF-002, ...)
- 설명 (예: "전기 배출계수 (한전 기준)")
- 값 (kgCO₂e/단위)
- 단위 (kWh, kg, km 등)
- 버전 (1.0, 1.1, ...)
- 적용 기간
- 생성일, 수정일

#### 5.3.2 버전 관리
- 배출계수 변경 시 자동으로 버전 증가
- 이전 버전 데이터도 조회 가능
- "버전 비교" 기능 (선택): 두 버전의 차이 표시

#### 5.3.3 권한 (향후)
- 관리자: 등록, 수정, 삭제
- 분석가: 조회만 가능

## 6. 데이터 모델 (개요)

### 6.1 핵심 엔티티

**Products** (제품)
- id, name, description, created_at

**EmissionFactors** (배출계수)
- id, code, description, value, unit, version, applicable_from, created_at, updated_at

**PCFData** (PCF 계산 데이터)
- id, product_id, raw_materials(kg), electricity(kWh), transportation(km), scope(1|2|3), stage(원재료|생산|물류|판매), calculated_pcf, calculated_at, source (manual|import)

**ImportLogs** (임포트 이력)
- id, file_name, row_count, status(success|failed), error_message, imported_at

### 6.2 관계
```
Products (1) ←→ (N) PCFData
EmissionFactors (1) ←→ (N) PCFData
ImportLogs (1) ← (N) PCFData (역방향 추적)
```

## 7. PCF 계산 로직

```
PCF = (Raw Materials × EF_RM) 
    + (Electricity × EF_EL) 
    + (Transportation × EF_TR)

여기서:
- EF_RM: 원재료 배출계수 (kgCO₂e/kg)
- EF_EL: 전기 배출계수 (kgCO₂e/kWh)
- EF_TR: 운송 배출계수 (kgCO₂e/km)
```

Scope 분류:
- **Scope 1**: 직접 배출 (생산 과정)
- **Scope 2**: 간접 배출 (구매 전기)
- **Scope 3**: 기타 간접 배출 (운송, 폐기 등)

## 8. 에러 처리 및 안정성

### 8.1 일반적인 에러 시나리오

| 시나리오 | 에러 메시지 | 대응 |
|---------|-----------|------|
| 데이터 로드 실패 | "데이터를 불러올 수 없습니다. 잠시 후 다시 시도해주세요" | 자동 재시도 (3회) |
| 필터 조건 오류 | "선택한 필터 조건에 맞는 데이터가 없습니다" | 필터 초기화 제안 |
| Excel 업로드 실패 | "파일 업로드에 실패했습니다" | 파일 크기, 형식 확인 안내 |
| 네트워크 오류 | "네트워크 연결을 확인해주세요" | 재시도 버튼 제공 |

### 8.2 데이터 유효성
- NULL 값은 기본값 0으로 처리
- 음수 값은 데이터 입력 시 거절
- 배출계수 변경 시, 과거 데이터는 변경 전 계수로 유지

## 9. 성능 및 확장성

### 9.1 성능 고려사항
- **캐싱**: 배출계수, 제품 목록은 1시간 캐시
- **페이지네이션**: 차트 데이터는 최대 1년 범위로 제한
- **인덱싱**: product_id, scope, stage 컬럼에 인덱싱

### 9.2 확장 계획 (향후)
- 리포트 내보내기 (PDF, CSV)
- 예측 분석 (트렌드 기반 배출량 예측)
- 벤치마킹 (산업 평균과 비교)
- 알림 (배출량 증가 시 자동 알림)
